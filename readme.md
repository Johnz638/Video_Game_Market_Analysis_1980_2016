# Video Game Market Analysis (1980–2016)

Exploratory analysis of global video game sales using Python and Plotly.

**Objectives**
- Identify global sales trends over time
- Analyze platform market share
- Compare regional genre preferences (NA, EU, JP)
- Detect critic vs user score perception gaps

**Tools & Skills**
- **Python:** Pandas, Plotly, Seaborn
- **Techniques:** Data cleaning, time series analysis, 
  normalization, interactive dashboarding

**Dataset**
## Video Game Sales — Kaggle (https://www.kaggle.com/datasets/gregorut/videogamesales)  
16,719 titles | Scraped from VGChartz

**Key Findings**

- PS2 dominated with 18.5% global market share
- Console wars peak (2005–2008): X360, PS3, Wii competed simultaneously
- Japan shows disproportionate preference for RPGs (38%) vs Shooters (3.7%)
- Users rate Adventure and Platform genres significantly higher than critics
